# Lucide account-status icons

Source: [Lucide Icons](https://github.com/lucide-icons/lucide/tree/c29c276f16590cf017126671535ad8c792be64d8/icons), revision `c29c276f16590cf017126671535ad8c792be64d8`.

Only `circle-check.svg`, `shield-check.svg`, `shield.svg`, `rotate-ccw-clock.svg` (history) and `clock.svg` are included. Geometry is unchanged; stroke colors were adapted to the chooser palette. All files are served locally, without a library package or CDN.

Lucide is licensed under the ISC license. The Feather-derived `clock.svg` is covered by the MIT notice. Both upstream copyright and permission notices are preserved in [LICENSE](LICENSE), copied in full from the same revision. See the [official license](https://lucide.dev/license).

Status icons have empty alternative text and are hidden from assistive technology because adjacent visible text supplies their meaning once in each account button’s accessible name.
