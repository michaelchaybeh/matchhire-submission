# MatchHire Assessment Submission

This private repository is reserved for the hiring-team assessment deliverables.

Application code, tests, and supporting documentation will be added after scope approval.

Only explicitly approved assessment materials belong here.

Do not include:
- Private project coordination notes
- Internal planning and AI instructions
- Obsidian settings
- Credentials or secrets
- Unapproved internal documentation

Required AI-use disclosures and verification evidence must be included when applicable.

Do not grant evaluator access without Product Owner approval.
